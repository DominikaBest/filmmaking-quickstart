# From Page to Screen

Live presentation: https://dominikabest.github.io/filmmaking-quickstart/

A ten-step beginner walkthrough using one Empty Chair teaching example: scene, flip, palette, references, still test, storyboard, video prompts, clip generation, edit, sound/export.

Open index.html. The current presentation uses workflow.css, workflow.js and library-data.js. Ten filmmaker/reference galleries each contain six images, with film and cinematography credits and source links. Diagrams are illustrative sketches, not generated production frames. The page supplies prompts and planning examples; generation and editing happen in the student's chosen tools.

Scene questions and sequencing are adapted from the existing directing workspace. The UF teaching label is “The hottest guy wants you.” Storyboard timing is illustrative, not measured performance. The chapter does not promise views.

Navigation, galleries, assets and storyboard structure validated with a DOM smoke test. All 60 reference images checked as valid image files.
